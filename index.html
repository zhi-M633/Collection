数据与隐私

数据仅保存在本机

本机备份

数据默认只保存在当前浏览器。换手机、清缓存、换浏览器或换域名前，请先导出备份。

云端账号

云同步尚未配置。你仍然可以正常在本机使用，并通过“导出备份”迁移数据。

如需跨设备同步，请按 README 创建你自己的 Supabase 项目，然后把 Project URL 和 anon public key 填入 index.html，并确保 supabase.min.js 与页面放在同一目录。

云端账号

首次登录不会上传数据；上传需要你在下方单独授权。若本机保留过该账号的授权，登录后会沿用。

还没有账号？

忘记密码可在 Supabase 控制台 → Authentication → Users 中重置。

注册会创建你自己的云端账号。你的邮箱将发送到你的 Supabase 项目用于登录；作品数据不会自动上传，稍后仍需单独授权。

云端同步授权

授权后会发生：

  • 从你的 Supabase 云端账号读取作品数据，并按更新时间合并到本机。
  • 将本机的作品名称、作者/导演、国家/地区、评分、评价、介绍、两套标签、封面图片和删除记录上传。
  • 作品数据中不包含：本机作者输入历史、TMDB Key、主题偏好。同步请求本身仍会向你的 Supabase 项目暴露 IP 和常规请求信息。

云端由你自己的 Supabase 项目托管，行级权限（RLS）确保只有你的账号能读写；传输使用 HTTPS。当前未启用端到端加密，Supabase 作为服务方技术上可访问存储内容。

同步控制

云同步已启用。

撤回授权与云端数据

撤回授权后，本机数据保留，但不再读取或上传云端。删除云端数据前，请先在其他设备上暂停同步，否则它们可能重新上传。

隐私设置

默认关闭。关闭时只使用本机作者历史，不会向第三方发送任何搜索词。开启后，输入作者名会发送给对应服务。

更多安全与隐私说明
  • 本机数据保存在浏览器 LocalStorage，默认不上传；只有你授权并启用云同步后，修改才会自动上传。建议为手机和电脑设置锁屏密码，不要在公共设备上登录。
  • 云端同步需要你在这里勾选授权；可随时暂停或撤回。退出登录不会删除本机数据。
  • 创建账号后，建议在 Supabase 后台关闭新用户注册，只保留你自己的账号；并妥善保管账号密码。
  • 本应用没有统计、广告或第三方追踪脚本。Supabase SDK 已放在本目录，避免从第三方 CDN 加载。
  • 外部封面图片会由对应图片服务器加载；应用已设置不发送来源页面信息，但图片服务器仍能看到你的 IP。
  • 免费 Supabase 项目连续 7 天不活跃会被暂停，控制台点一次恢复即可。

切换账号确认

继续切换会清空本机数据；旧账号的云端数据不会被删除。为了不丢失尚未同步的内容，建议先导出备份。
